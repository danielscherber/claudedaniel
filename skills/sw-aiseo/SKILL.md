# KI-SEO — Inhalte für KI-Plattformen optimieren

KI-SEO unterscheidet sich von klassischem SEO in einem zentralen Punkt: **Nicht Ranking ist das Ziel, sondern Zitierung.** Eine gut strukturierte Seite kann von ChatGPT oder Perplexity zitiert werden, auch wenn sie auf Seite 2 rankt. KI-Systeme wählen Quellen nach Inhaltsqualität, Struktur und Vertrauen — nicht nach Rankingposition.

**Kritische Kennzahlen:**
- KI-Overviews erscheinen in ~45 % aller Google-Suchen
- Optimierte Inhalte werden 3× häufiger zitiert als nicht-optimierte
- Statistiken und Quellenangaben steigern die KI-Sichtbarkeit um +40 %
- Keyword-Stuffing reduziert KI-Sichtbarkeit um −10 % (Princeton GEO-Studie, KDD 2024)

---

## Die 3 Säulen

```
1. Structure  — Inhalte extrahierbar machen
2. Authority  — Inhalte zitierwürdig machen
3. Presence   — Dort sein, wo KI sucht
```

---

## Säule 1: Structure — Inhalte für KI-Extraktion aufbauen

### Konversationsfokus statt Keyword-Fokus

KI-Systeme beantworten Fragen — keine Keywords. Jede Seite beantwortet alle natürlichen Folgefragen, die ein Mensch stellen würde.

❌ Optimiert für: „Imagefilm Fulda"
✅ Optimiert für: Was kostet ein Imagefilm? Wie lange dauert es? Wann macht es Sinn? Was ist der Unterschied zu einem Erklärvideo?

### Fragen als Überschriften (H1, H2, H3)

Überschriften sind direkte, menschlich formulierte Fragen. Der folgende Text beantwortet sie sofort — wie in einem echten Gespräch.

```
H1: Wann lohnt sich ein Imagefilm für ein Handwerksunternehmen?
H2: Was kostet ein Imagefilm bei stillworks?
H2: Wie lange dauert eine Imagefilm-Produktion?
H3: Was ist der Unterschied zwischen Imagefilm und Recruiting Video?
```

### BLUF — Antwort zuerst (Bottom Line Up Front)

KI extrahiert meist den ersten Satz einer Antwort. Die Kernaussage kommt sofort, die Erklärung danach.

❌ „Wenn es um die Frage geht, was ein Imagefilm kostet, hängt das von vielen Faktoren ab..."
✅ „Ein Imagefilm bei stillworks kostet zwischen 8.000 und 20.000 €, abhängig von Konzept, Drehtagen und Post-Produktion."

**Optimale Absatzlänge für KI-Extraktion: 40–60 Wörter**

### Formatierungsregeln

| Format | Wann einsetzen |
|---|---|
| Kurze Frage-Antwort-Blöcke | FAQ-Inhalte, überall im Text |
| Tabellen | Vergleiche (z.B. Imagefilm vs. Erklärvideo) |
| Nummerierte Listen | Prozesse, Schritte |
| Aufzählungszeichen | Echte Listen, nicht Fließtext |

Mindestens eine Vergleichstabelle pro Leistungsseite — KI extrahiert diese bevorzugt für Vergleichsanfragen.

## Säule 2: Authority — Inhalte zitierwürdig machen

### E-E-A-T — Expertise, Erfahrung, Autorität, Vertrauen

KI-Plattformen bevorzugen Quellen mit nachweisbarer Expertise. Vertrauen entsteht durch konkrete Daten, echte Erfahrungen und transparente Autorenschaft.

**Messbarer Effekt (Princeton GEO-Studie, KDD 2024):**

| Maßnahme | Sichtbarkeitsgewinn |
|---|---|
| Quellen zitieren | +40 % |
| Statistiken einbinden | +37 % |
| Expertenzitate | +30 % |
| Autoritative Sprache | +25 % |
| Lesbarkeit verbessern | +20 % |
| Keyword-Stuffing | **−10 %** |

### Eigene Primärdaten veröffentlichen

KI zitiert Seiten, die eigene Zahlen haben — nicht nur fremde Studien. Konkrete eigene Daten auf jeder Seite:
- Anzahl Produktionen seit Gründung
- Jahre Erfahrung
- Kundenanzahl oder Branchen
- Konkrete Timelines, die eingehalten werden

### Echte Kundenzitate

Format: „[Direktzitat]" — Vorname Nachname, Position, Unternehmen
Erhöht Zitierhäufigkeit um ~30 %.

### Autorenschaft

Jeder Inhalt braucht einen sichtbaren Autor:
- Name + Funktion
- Verlinktes LinkedIn-Profil
- Kurz-Bio
- Veröffentlichungs- und Aktualisierungsdatum

### Frische-Signale

Undatierte Inhalte verlieren gegen datierte. Pflicht auf jeder Seite:
- „Veröffentlicht: [Datum]"
- „Zuletzt aktualisiert: [Datum]" — bei jeder Änderung aktualisieren

| Inhaltstyp | Mindest-Update |
|---|---|
| Preisangaben | Sofort bei Änderung |
| Leistungsseiten | Jährlich |
| FAQs | Halbjährlich |

## Säule 3: Presence — Dort sein, wo KI sucht

Brands sind **6,5× häufiger** über Drittquellen zitiert als über die eigene Domain. Die eigene Website ist nur ein Teil der Gleichung.

**Zitierungsquellen nach Anteil (ChatGPT):**
- Wikipedia: 7,8 %
- Reddit: 1,8 %
- Branchenpublikationen, Verzeichnisse, YouTube: Rest

### Maßnahmen

| Kanal | Warum | Priorität |
|---|---|---|
| Google Business Profile | KI greift direkt auf GBP-Daten zu | Sehr hoch |
| YouTube-Kanal mit Transkripten | YouTube wird von Google AI Overviews häufig zitiert | Sehr hoch |
| Branchenverzeichnisse | Erhöhen Entity-Autorität | Hoch |
| Lokale Presseerwähnungen | PR-Artikel = Drittquellen-Signal | Hoch |
| Podcast/Interview-Auftritte | Als Experte zitiert zu werden > eigener Blog | Mittel |

### NAP-Konsistenz (Name, Adresse, Telefon)

Auf allen Plattformen identisch. Abweichungen verwirren KI-Entitätserkennung.

## Semantischer Reichtum

Keywords nicht wiederholen — verwandte Konzepte in verschiedenen Variationen erklären. Eine Seite zu „Imagefilm" verwendet auch: Unternehmensfilm, Corporate Film, Bewegtbild, Employer Branding, Vertrauensaufbau, Conversion-Video.

Ziel: **Eine Seite beantwortet ein Thema vollständig**, nicht einen Begriff mehrfach.

---

## Schema-Markup

Strukturierte Daten helfen KI-Systemen, Inhalte ohne Interpretation zu verstehen. Seiten mit korrektem Schema werden **30–40 % häufiger zitiert**.

### Pflicht pro Seitentyp

| Seite | Schema-Typen |
|---|---|
| Alle Seiten (global) | `Organization` + `LocalBusiness` + `BreadcrumbList` |
| Leistungsseiten | + `Service` + `FAQPage` |
| Seiten mit Video | + `VideoObject` |
| Blog/Artikel | + `Article` + `Person` (Autor) |
| Startseite | + `WebSite` |

### Implementierung in Webflow

JSON-LD → Seiten-Settings → Custom Code → Head

**Wichtig:** JSON-LD im `<head>`, nicht als HTML-Attribute.

Fertige Templates → Siehe `KI-SEO-Leitfaden-stillworks.docx` (Teil 2)

## KI-Bot-Zugang (robots.txt)

Blockierte Bots = keine Zitierung auf der jeweiligen Plattform.

```
User-agent: GPTBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: anthropic-ai
Allow: /

User-agent: Google-Extended
Allow: /

# Trainings-Crawler ohne Suchbezug blockieren
User-agent: CCBot
Disallow: /
```

## Häufige Fehler

| Fehler | Folge |
|---|---|
| Keyword-Stuffing | −10 % KI-Sichtbarkeit |
| Kein Autor, kein Datum | Verliert gegen datierte Inhalte |
| KI-Bots blockiert | Plattform kann nicht zitieren |
| Gated Content | KI kann nicht zugreifen |
| Keine Drittquellen-Strategie | Eigene Website allein reicht nicht |
| Thin Content ohne eigene Daten | Wird nicht als Primärquelle behandelt |
| Antwort erst am Absatz-Ende | KI extrahiert ersten Satz — falsche Aussage zitiert |
